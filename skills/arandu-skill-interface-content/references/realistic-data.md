# Realistic data

Save as `docs/content/realistic-data.md` and use it in views under construction, seeds, tests and screenshots. Never Lorem Ipsum, "Usuário Teste", "Empresa X", "Produto 1", "R$ 0,00" as a sample, or `foo@bar.com`.

## What to include

| Kind | Rule | Examples |
|---|---|---|
| People | common Brazilian names, varied length and origin | Ana Paula Ribeiro, João Pedro dos Santos, Maria Eduarda Nakamura, Raimundo Nonato Silva Filho |
| Companies | the niche's real kinds of business, with the legal suffix | Padaria Central Ltda., Oficina Mecânica Irmãos Prado, Clínica Sorriso Pleno S/S, Transportes Rio Verde EIRELI |
| Documents | valid **format**, clearly fictitious numbers; never a real person's CPF | CPF 123.456.789-09 (check digits valid), CNPJ 12.345.678/0001-95 |
| Money | `R$` + non-breaking space, thousands with `.`, cents with `,`; realistic spread | R$ 89,90 · R$ 1.280,00 · R$ 47.350,12 |
| Dates and times | `dd/mm/aaaa`, `HH:mm`, relative where the product uses it | 25/10/2026 · 14:32 · "há 3 dias" |
| Addresses | street, number, neighbourhood, city/UF, CEP | Rua Augusta, 1508 — Consolação, São Paulo/SP, 01304-001 |
| Phones | `(DD) 9XXXX-XXXX` | (11) 98765-4321 |
| Volumes | the niche's real scale, plus 0, 1 and 1 000+ | 0 cobranças · 1 cobrança · 1.247 cobranças |
| Statuses | every status in the glossary, in realistic proportions | 62 % Paga, 30 % Emitida, 8 % Vencida |
| Errors | the niche's real failures | boleto recusado pelo banco, CNPJ inativa na Receita, e-mail do cliente devolvido |
| Extremes | the shortest and longest plausible values | "Bar do Zé" · "Associação Beneficente dos Moradores do Jardim São Luís e Adjacências" |

## Rules

- Data only illustrates. Never present invented customers, testimonials or counts as facts on public pages (`arandu-skill-interface-copywriting` rule); in screenshots of the product, sample data is fine and labelled as such when published.
- Keep fictitious documents fictitious: no real CPF or CNPJ of a person or company, no real card numbers (use the payment provider's test numbers).
- Personal data in seeds follows LGPD hygiene: nothing copied from production.
